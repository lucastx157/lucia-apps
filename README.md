# LucIA Apps

Site da LucIA Apps — *aplicativos reais para pessoas normais*.

Site estático (um `index.html`, sem build). Pra ver no computador, é só abrir o `index.html` no navegador.

## Onde mexer
- **WhatsApp**: procure `const WHATS=` no `index.html` e coloque o número com DDI e DDD, só dígitos.
- **Planos e preços**: seção `id="planos"`.
- **Perguntas frequentes**: seção com a classe `faq`.

## Publicar
Funciona em GitHub Pages, Vercel ou Netlify sem configuração (pasta raiz).
